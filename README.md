# 広島三育学院 Web School Guide

48P学校案内の内容をもとにした、学校案内Webサイトです。
ビルド不要の静的HTMLなので、GitHub Pages にそのまま置いて公開できます。

## ページ構成

| ファイル | 内容 |
|---|---|
| index.html | トップ（プロローグ、こんな気持ちありませんか、4つの場面、数字、保護者へ、高校から入学） |
| about.html | 三育を知る（教育理念、モットー、4つの品性、沿革、世界のネットワーク） |
| live.html | 暮らす（寮教育、寮の一日・一週間、生徒がつくる寮、部屋、ルール、年間行事、帰省・家族） |
| learn.html | 学ぶ（少人数・学年担当制、カリキュラムマップ、英語・留学） |
| do.html | 動く（ソアン、ソアン×探求、労作、体験プログラム、音楽、部活動） |
| believe.html | 根を張る（礼拝・安息日、聖書、信仰の歩み、キリスト教を知らないご家庭へ） |
| grow.html | 育つ・進路（変化の道のり、保護者・在校生の声、進路、卒業後のつながり） |
| admission.html | 入学案内（見学・体験、日程、入試制度、高校から、学費・奨学金、FAQ、アクセス、お問い合わせ） |
| 404.html | ページが見つからないとき |
| assets/css/style.css | 全ページ共通のデザイン |
| assets/js/main.js | スマホのメニュー開閉、スクロール時の表示 |
| assets/img/ | 写真・ロゴ |
| sitemap.xml / robots.txt | 検索エンジン向け |

ヘッダー（メニュー）とフッターは各ページに同じものが入っています。メニューを変えるときは全ページを同じように直してください。

## 公開前にやること

### 1. 独自ドメインに書き換え
`https://guide.hiroshima.saniku.ed.jp` を、取得したドメインにすべて置き換えます（全HTML、sitemap.xml、robots.txt）。

### 2. 「要確認」表示の解消
赤枠の「要確認」「仮」「差し替え」は、確認が済んでいない箇所です。主なもの：

- 郵便番号（729-1493 と 729-1406 のどちらが正しいか）
- 進学率・入試方法の割合（最新データ）
- 寮の人数・部屋・ルール（寮監確認）、卒業生の仲間「4,000人以上」
- 中学の週間予定と部活動日（水・日）・シーズンスポーツ（月）の整合
- 学費が月額表記か
- 恩おくり奨学金の名称・設立経緯の表記
- 卒業生（サッカー）の氏名・掲載許諾
- FAQの「仮」回答（体調不良時、ホームシック、連絡方法、スマホの利用時間、持ち物）
- 今年度の日程表、募集要項PDF、LINE公式アカウントURL、申込フォームURL
- キャンパスマップ（施設名と配置）、アクセス経路

確認が済んだら、各「要確認」タグ（`<span class="kari">…</span>`）を消してください。
まとめて非表示にしたい場合は、style.css 冒頭近くの `/* .kari{display:none !important} */` の前後のコメント記号を外します。

### 3. 写真の差し替え
いまの写真の多くは、写真選抜PDFから抜き出した低解像度（幅250px前後）の仮画像です。同じファイル名で高解像度版（長辺1600〜2400px、JPEG）に置き換えれば、HTMLを触らずに差し替わります。
「写真準備中」の枠（`<div class="ph">`）は、撮影後に `<img>` に置き換えます。

注意：入浴場面の写真は使いません。生徒の氏名は載せません（学年・性別のみ）。

## GitHub Pages ＋ お名前.com での公開手順

1. GitHubで新しいリポジトリを作成（例：`hsg-school-guide`）し、このフォルダの中身をすべてアップロード
2. リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を `main` / `(root)` に設定
3. 同じ画面の Custom domain に取得したドメイン（例：`www.○○○.jp`）を入力して保存（`CNAME` ファイルが自動で作られます）
4. お名前.com Navi → DNS設定 で、次のレコードを追加
   - `www` を使う場合：ホスト名 `www`、TYPE `CNAME`、VALUE `（GitHubユーザー名）.github.io`
   - `www` なし（ドメイン直下）も使う場合：TYPE `A` で次の4件
     `185.199.108.153` / `185.199.109.153` / `185.199.110.153` / `185.199.111.153`
5. DNSが反映されたら（数時間〜最大1日程度）、GitHubの Pages 設定で「Enforce HTTPS」にチェック

GitHubのIPアドレスや画面の名称は変わることがあります。設定時はGitHub公式ドキュメント「Managing a custom domain for your GitHub Pages site」も確認してください。
